# Website QA — 28 September 2026

## Fixes

- Deferred video sources until at least 15% of the video enters the viewport. Previously all four below-the-fold gallery videos had loaded media on the initial visit. Their combined file size is approximately 29 MB; this is deferred media capacity, not a measured transfer saving. Visible videos still play automatically, muted and looping. Off-screen videos pause, manual pauses persist, and reduced-motion preferences remain respected.
- Updated the mobile menu's accessible label when open; Escape returns focus to its button. Outside clicks and breakpoint changes reset the menu.
- Locked background scrolling while a project dialog is open, reserving the scrollbar gutter to avoid a horizontal layout jump.
- Rejected whitespace-only enquiry names/details and phone numbers containing letters. Editing a prepared enquiry clears the old WhatsApp link, preventing submission of stale details.
- Restored initial URL fragments after JavaScript renders the page, so direct section URLs land correctly.

- Confirmed all three history paragraphs remain visible on mobile.

- Existing native CSS smooth scrolling and reduced-motion override retained; no JavaScript scroll loop added.

## Scope limits

Browser viewport testing is not a physical-device or cross-browser certification. No throttled-network Lighthouse run or frame-time benchmark was performed, so there is no numeric performance-score or zero-lag claim. iOS Safari and older devices require a separate device pass.
